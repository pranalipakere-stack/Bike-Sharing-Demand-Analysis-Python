# Bike Sharing Demand Analysis using Python

## Project Overview

This project focuses on analysing bike-sharing rental data using Python. The main objective is to understand customer rental behaviour and identify demand patterns based on time, season, weather and other factors.

The project uses Exploratory Data Analysis (EDA) and data visualization to discover useful business insights.

## Dataset Information

- **Dataset:** Bike Sharing Dataset
- **Source:** UCI Machine Learning Repository
- **Records:** 17,379
- **Columns:** 17
- **Time Period:** 2011–2012
- **Target Column:** `cnt` (Total Bike Rentals)

## Key Findings

- Total bike rentals: 3,292,679.
- Average hourly rentals: 189.46.
- Highest demand occurs at 5 PM.
- Lowest demand occurs at 4 AM.
- Fall has the highest average seasonal demand.
- September has the highest average monthly demand.
- Thursday has the highest average weekday demand.
- Registered users contribute approximately 81.17% of total rentals.
- Temperature has a moderate positive correlation with rental demand.
- Humidity has a negative correlation with rental demand.

## Conclusion

This project helped identify important patterns in bike rental demand using Python.

The analysis shows that rental demand changes based on time, season, weather and customer type. These findings can help bike-sharing businesses understand customer behaviour and improve operational planning.
